# 🚀 Projetos

## 🖥️ CentralSwitchs

Um dos meus principais projetos pessoais.

O **CentralSwitchs** é uma aplicação desenvolvida em Python para facilitar o gerenciamento e acesso a switches de rede.

A ideia surgiu da necessidade de substituir processos baseados em menus `.BAT` por uma aplicação gráfica mais organizada e fácil de utilizar.

### ⚙️ Principais funcionalidades

- 🏢 Organização por Sites
- 📁 Organização por Grupos
- 🔀 Cadastro de Switches
- 🌐 Gerenciamento de endereços IP
- 📡 Teste de conectividade
- 🔐 Acesso SSH
- 🖥️ Integração com PuTTY
- 🗄️ Banco de dados SQLite
- 🖼️ Interface gráfica
- 📦 Geração de executável para Windows
